**Coordinates Jr.** is a program I developed so that programmers who automate tasks don't waste time looking up the mouse's X and Y coordinates.

### ✨ How It Works
Forget about typing coordinates manually. My workflow is faster:

1.  Move your mouse to the target position on the screen.
2.  Press the **SPACEBAR** key to display the X and Y coordinates.
3.  **Select the coordinates** displayed in the program.
4.  Press **Ctrl + X** to cut them and paste directly into your code.

That's it. Fast, simple, and efficient.

### 🚀 Perfect For
This tool is built for automation in both languages:

-   **Python:** `pyautogui.click(x, y)` , `pyautogui.moveTo(x, y)`
-   **Java:** `robot.mouseMove(x, y)` using `java.awt.Robot`
